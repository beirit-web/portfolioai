# Django-Projekt: Wohnungsassistent Bodensee

## Ziel

Erstelle eine Django-App, die automatisch nach Wohnungen sucht, Suchfilter speichert, passende Treffer bewertet, den Nutzer benachrichtigt und bei der Wohnungsbewerbung hilft.

Zuerst soll ein sauberes MVP gebaut werden. Echte Anbieter/Scraping kommen erst später und nur, wenn es rechtlich/technisch erlaubt ist.

---

# Phase 1: Projektgrundlage

## Ticket 1: Django-Projekt erstellen

* Neues Django-Projekt erstellen
* App `housing_search` erstellen
* `.env` vorbereiten
* Keine Zugangsdaten im Code speichern
* SQLite für Entwicklung
* PostgreSQL später möglich
* Login/Logout vorbereiten
* Nur eingeloggte Nutzer dürfen die App nutzen

---

## Ticket 7: Rechtliche Anbieter-Regel

Keine Plattform darf blind gescrapt werden.

Vor echter Anbindung prüfen:

* Gibt es API?
* Gibt es RSS?
* Gibt es E-Mail-Suchauftrag?
* Erlauben Nutzungsbedingungen automatische Abfrage?
* Falls nein: keine automatische Abfrage dieser Plattform

In der App soll ein Hinweis stehen:

> Die Nutzung externer Wohnungsportale muss deren Nutzungsbedingungen beachten. Wenn automatische Abfragen nicht erlaubt sind, soll eine offizielle API, RSS, E-Mail-Suchauftrag oder manuelle Importfunktion genutzt werden.

# Ticket 34: Anbieter-Compliance und erlaubte Datenquellen

## Ziel

Sicherstellen, dass neue Wohnungsanbieter nur über zulässige und technisch saubere Schnittstellen angebunden werden.

## Anforderungen

Vor jeder Anbieter-Anbindung prüfen:

* Gibt es eine offizielle API?
* Gibt es einen RSS-Feed?
* Gibt es Suchaufträge per E-Mail?
* Gibt es eine dokumentierte Schnittstelle?
* Erlauben die Nutzungsbedingungen automatisierte Zugriffe?

## Nicht umsetzen

Die Anwendung darf keine Funktionen enthalten für:

* Umgehung von Login-Schutz
* Umgehung von Captchas
* Umgehung von Anti-Bot-Systemen
* Umgehung von Zugriffsbeschränkungen
* Automatisierte Massenabfragen entgegen Nutzungsbedingungen

## Ergebnis

Jeder neue Provider muss eine Dokumentation besitzen:

* Anbietername
* Datenquelle
* API vorhanden
* RSS vorhanden
* E-Mail-Import möglich
* Status:

  * erlaubt
  * prüfen
  * nicht angebunden
