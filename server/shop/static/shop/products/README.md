# Product image provenance

These 14 images are AI-generated demonstration assets, not photographs of actual
products for sale. Generated with the built-in image_gen tool on 2026-10-02.
Each subject was generated separately. The selected PNG files were resized to
768 x 1024 and saved locally as WebP at quality 86 with ImageMagick.
No external image service, API key or image request is required at runtime.

## Shared prompt

```text
Use case: product-mockup. Create one photorealistic bakery catalog product photograph. Portrait 3:4 image. Entire cake and simple white ceramic plate visible, centered, occupying about 70% of the image width, enough margin so no cake or plate edges are clipped. Gentle three-quarter angle looking slightly down. Bright white tabletop, very light neutral gray background, soft natural daylight, sharp appetizing realistic baked texture. No text, labels, logo, people, props, collage or other cakes. Subject: 
```
