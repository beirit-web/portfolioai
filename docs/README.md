## Dokumentation pflegen

Jede Anleitung wird auf der zugehörigen Seite gepflegt und von anderen Stellen
verlinkt. App-READMEs beschreiben die Besonderheiten ihrer Anwendung. Bei
Änderungen an Ordnern, Routen, Build-Zielen oder Prüfkommandos wird die zuständige
Seite mit aktualisiert. Historische Einzelmessungen und lokale Archivpfade
gehören nicht zur laufenden Projektanleitung.
