{% if initial_lang|slice:':2' == 'ru' %}Какую задачу решало приложение?{% else %}Welche Aufgabe sollte die Anwendung lösen?{% endif %}

{% if initial_lang|slice:':2' == 'ru' %}Приложение объединяло информацию о немецко-русском языковом сопровождении, структурированные запросы и организацию встреч в одном адаптивном интерфейсе. Оно было рассчитано на телефонные разговоры, онлайн-встречи и личное сопровождение, в том числе при контакте с учреждениями.{% else %}Die Anwendung bündelte Informationen zur deutsch-russischen Sprachmittlung, strukturierte Anfragen und die Organisation von Terminen in einer responsiven Oberfläche. Sie war für Telefonate, Online-Gespräche und persönliche Begleitung konzipiert, unter anderem bei Kontakten mit Einrichtungen.{% endif %}

{% if initial_lang|slice:':2' == 'ru' %}Как выглядел типичный процесс?{% else %}Wie war der typische Ablauf aufgebaut?{% endif %}

{% if initial_lang|slice:':2' == 'ru' %}Пользователи могли ознакомиться с вариантами языкового сопровождения, создать учетную запись, передать структурированные контактные данные и запросить доступную дату. Данные проверялись на сервере, сохранялись и были доступны для дальнейшей обработки в защищенной административной области.{% else %}Nutzende konnten sich über die vorgesehenen Sprachmittlungsszenarien informieren, ein Benutzerkonto anlegen, strukturierte Kontaktdaten übermitteln und einen verfügbaren Termin anfragen. Die Angaben wurden serverseitig geprüft, gespeichert und konnten anschließend in einem geschützten Verwaltungsbereich bearbeitet werden.{% endif %}

{% if initial_lang|slice:':2' == 'ru' %}Какие данные и роли учитывались?{% else %}Welche Daten und Rollen wurden berücksichtigt?{% endif %}

{% if initial_lang|slice:':2' == 'ru' %}Модель данных охватывает учетные записи, контактные данные, профили, запросы на встречи и их статусы. Публичные формы, личные пользовательские области и административные функции разделены по назначению и правам доступа.{% else %}Das Datenmodell umfasst Benutzerkonten, Kontaktdaten, Profile, Terminanfragen und deren Bearbeitungsstatus. Öffentliche Formulare, persönliche Benutzerbereiche und administrative Funktionen sind nach Aufgabe und Zugriffsrechten voneinander getrennt.{% endif %}

{% if initial_lang|slice:':2' == 'ru' %}Как реализованы проверка и безопасность?{% else %}Wie wurden Validierung und Sicherheit umgesetzt?{% endif %}

{% if initial_lang|slice:':2' == 'ru' %}Формы проверяются на стороне Django, защищенные страницы требуют авторизации, а действия с пользовательскими данными используют предусмотренные фреймворком механизмы сессий и CSRF-защиты. Согласия и обязательные поля учитываются непосредственно при обработке формы.{% else %}Formulare werden auf Django-Seite validiert, geschützte Ansichten setzen eine Anmeldung voraus und Aktionen mit Benutzerdaten verwenden die Session- und CSRF-Schutzmechanismen des Frameworks. Einwilligungen und Pflichtangaben werden direkt in der Formularverarbeitung berücksichtigt.{% endif %}

{% if initial_lang|slice:':2' == 'ru' %}Как была реализована многоязычность?{% else %}Wie wurde die Mehrsprachigkeit umgesetzt?{% endif %}

{% if initial_lang|slice:':2' == 'ru' %}Сама языковая услуга была предназначена исключительно для немецкого и русского языков. Отдельно от этого пользовательский интерфейс технически переводится на немецкий, русский и украинский языки с помощью данных перевода в формате JSON. Украинский является только языком интерфейса, а не языком перевода или устного сопровождения.{% else %}Der Sprachservice selbst war ausschließlich für Deutsch und Russisch vorgesehen. Unabhängig davon wird die Benutzeroberfläche technisch über JSON-Übersetzungsdaten auf Deutsch, Russisch und Ukrainisch ausgegeben. Ukrainisch ist dabei nur eine Sprache der Oberfläche, keine angebotene Übersetzungs- oder Dolmetschsprache.{% endif %}

{% if initial_lang|slice:':2' == 'ru' %}Как приложение эксплуатировалось технически?{% else %}Wie wurde die Anwendung technisch betrieben?{% endif %}

{% if initial_lang|slice:':2' == 'ru' %}Проект представляет собой серверное Django-приложение с шаблонами HTML, собственными CSS- и JavaScript-компонентами, базой данных, обработкой электронной почты и административной панелью. Развертывание было подготовлено для Musterhosting.{% else %}Das Projekt ist eine serverseitige Django-Anwendung mit HTML-Templates, eigenen CSS- und JavaScript-Komponenten, Datenbankanbindung, E-Mail-Verarbeitung und Administrationsoberfläche. Das Deployment wurde für Musterhosting eingerichtet.{% endif %}
