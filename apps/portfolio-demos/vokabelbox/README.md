# Vokabelbox

Die Vokabelbox ist als Lernmodul in die Sprachdienstleistungsplattform integriert.

Aktive Quellen:
- `sprachdienstleistungen/templates/pages/vokabelbox.html`
- `sprachdienstleistungen/assets/vokabelbox/`
- Django-Route: `/vokabelbox/` im Projekt `sprachdienstleistungen/`

Dieser Demo-Ordner bleibt als Altbestand erhalten. Sein Einstieg leitet zur Sprachplattform weiter; die Vokabelbox wird im Beirit-Portfolio nicht mehr als eigenständiges Projekt geführt.
