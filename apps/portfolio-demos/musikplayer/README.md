# Neumorphic Music Player

Let's polish up our UI skills and practice Flexbox layouts by creating the music player shown below -

![reference image](assets/reference-image.png)

### Instructions

> - All of the icons are from **Fontawesome**
> - The font we are using is _Inter_ from **Google Fonts**
> - Feel free to add a photo of an artist you like and include the artist and track name in the player
> - Mind the small details! Use different font weights, you should include `400` &  `800` and don't forget to create a `linear-gradient` for the track progress bar
> - To help with the neumorphic elements, you can use the generator [here](https://neumorphism.io/#e0e0e0)
> - As always, **pixel perfect** :)

## Integration in DeutschLive

Der aktive Player für eigene Audiodateien ist unter `/deutschlive/recordings` in DeutschLive integriert. Die Aufnahmen bleiben lokal im Browser und können als Datei heruntergeladen werden. `index.html` führt zum neuen Modul; die bisherigen Demo-Dateien bleiben als Projektarchiv erhalten.
